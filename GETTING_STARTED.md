# Getting Started - Quick Reference

Welcome to your new portfolio! Here's everything you need to know to get started.

## 🎉 What's Been Set Up

Your portfolio is ready with:
- ✅ Astrofy template installed and configured
- ✅ GitHub Pages deployment configured
- ✅ Personal information (name, location, LinkedIn)
- ✅ Placeholder for 2 featured projects
- ✅ Contact section
- ✅ Clean, simplified navigation
- ✅ Git repository initialized

## 🚀 Quick Start (3 Steps)

### Step 1: Preview Your Site Locally

```bash
npm run dev
```

Open http://localhost:4321 in your browser to see your portfolio.

### Step 2: Customize Your Content

Edit these files with your information:
- **`src/pages/index.astro`** - Update your bio and project details
- **`public/profile.webp`** - Replace with your photo

See [CUSTOMIZATION_GUIDE.md](./CUSTOMIZATION_GUIDE.md) for detailed instructions.

### Step 3: Deploy to GitHub Pages

```bash
# Commit your changes
git add .
git commit -m "Customize portfolio content"

# Create GitHub repository (if not done yet)
# Then push:
git remote add origin https://github.com/omarcarreon/portfolio.git
git push -u origin main

# Deploy to GitHub Pages
npm run deploy
```

See [DEPLOYMENT_GUIDE.md](./DEPLOYMENT_GUIDE.md) for detailed deployment instructions.

## ⚡ Pro Tips

1. **Use WebP images** for better performance (smaller file size)
2. **Keep project descriptions concise** - 1-2 sentences is perfect
3. **Test on mobile** - Most visitors will view on phones
4. **Update regularly** - Add new projects as you build them
